# Hi, I'm Jeff

I build software that explores the space where AI meets systems engineering — usually while I'm the only user. I ship tools I want to use, document them properly after the fact, and let the work speak.

## What I'm working on

| Project | What it is | Stack |
|---|---|---|
| [Bitler](https://github.com/ImJeffJayZ/Bitler) | Multiplayer geopolitical strategy game with LLM-driven AI superpowers | Godot 4, TypeScript, Python |
| [JSONSchema](https://github.com/ImJeffJayZ/JSONSchema) | Closed-loop framework for testing LLM agents — stateful Host drives a stateless LLM | Python |

Both repos are in active development. Bitler is a closed alpha; JSONSchema just hit `0.1.0`.

## How I work

I commit early, push often, and clean up later. The polish step — README, license, build hygiene — happens at publish time, not at commit time. My public GitHub is a curated version of what I actually build; my private Forgejo is messier.

I mostly write Python and TypeScript. I'm comfortable across the rest of the stack when a project demands it — recently Godot and Node, with bits of C# where the engine prefers it. I prefer boring tools that I can think in.

The interesting problems I keep coming back to: How do you make AI agents testable? How do you make a multiplayer system trustworthy enough that a player will lose to it? How do you keep a codebase navigable when it's the only artifact of a year's work?
